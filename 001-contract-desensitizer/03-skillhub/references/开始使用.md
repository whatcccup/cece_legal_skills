# 合同脱敏工具｜先读这份说明

## 先做三件事

1. 先完整解压 ZIP，不要在压缩包内直接启动。Mac 可将“合同脱敏工具.app”放到方便的位置，再双击打开。
2. **Windows：请先解压整个 ZIP，再双击文件夹里的 `Start.vbs` 启动。不要单独移动或删除 `Start.vbs`、`Start.bat` 和 `_support` 文件夹；需要换位置时，把整个文件夹一起移动。**首次需要 Python 3.9+ 和依赖，可复制下面的提示让 AI Agent 协助安装。
3. 浏览器打开本机地址 `http://127.0.0.1:18800/` 后，上传合同副本并复核。日常处理不需要 AI，也不需要联网。

App 已包含程序文件，但没有内置 Python 运行时。Mac 的程序文件收在 App 内；Windows 的程序文件在 `_support` 文件夹。请保留它们，不必自己打开。源码与测试在“其他资料/源码与测试.zip”，正常使用无需解压它。

## 可以直接发给 AI Agent

> 请帮我准备这个已解压的合同脱敏工具，不修改源码。先确认我的系统、Python 3.9+ 和文件夹位置。Mac 的程序目录是“合同脱敏工具.app/Contents/Resources/tool”，Windows 是“_support”。在程序目录创建 .venv，安装 requirements.txt，并实际验证能否打开本机页面。Mac 使用最外层 App，Windows 使用 Start.vbs。如果端口 18800 已被占用，先检查是否为已经打开的合同脱敏工具，告诉我旧工具的退出方法，或选择未占用端口；不要强制结束其他程序。如果系统拦截 App，向我解释原因和系统设置位置，由我自己确认是否打开，不自动解除系统防护。完成后告诉我今后双击哪个文件、安装的依赖和实际验证结果。

## Mac 提示“无法验证开发者 / Apple 无法检查此 App”

这是系统对未签名或未公证 App 的拦截，与端口占用不是一回事。本包没有 Apple 开发者签名或公证。

确认下载来源后，先尝试打开 App，然后进入 ** → 系统设置 → 隐私与安全性 → 安全性**，找到刚被阻止的 App，选择 **“仍要打开”**，按系统提示确认或验证身份。不同 macOS 版本的文字可能略有差异。

这只针对当前 App；不需要开启“任何来源”、关闭 Gatekeeper、授予完全磁盘访问权限，或运行批量移除隔离属性的命令。如果提示 App 已损坏或包含恶意软件，请停止并核对下载文件，不按本步骤强行打开。

Apple 官方说明：https://support.apple.com/zh-cn/102445

## 提示“端口 18800 已被占用”

这里说的是本机地址被程序使用，不是 AI 接口或 API Key 出错。

1. 先在浏览器访问 `http://127.0.0.1:18800/`。如果是已经运行的合同脱敏工具，可以直接使用。
2. 如果要换到新版，先在旧工具右上角点“退出”，再双击新版 App。只关闭浏览器标签页不会停止服务。
3. 如果打开的是其他程序，保留该程序，复制上面的提示让 AI 帮你检查并选择另一个空闲端口。也可以在程序目录执行 `python contract_app_server.py --port 18810 --open-browser`，以实际 Python 环境为准。

工具不会强制结束占用端口的程序。

## 提示找不到 Python、依赖安装失败或服务启动失败

Mac 双击最外层 **“启动排错.command”**，Windows 双击 **`Start.bat`**，查看具体错误；将错误文字连同文件夹位置交给 AI Agent。日志可能含本机路径，转发前请核对，勿附上合同正文。依赖下载失败时检查联网状态；Python 未安装时先让 AI 告知所需安装步骤。
