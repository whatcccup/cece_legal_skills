# 合同脱敏工具｜Windows 安装说明

适用于 Windows 10 / 11 的 64 位（x64）电脑。核心工具 v1.4.0。安装程序已完成构建与完整性检查；Windows 实机安装、启动和卸载仍待验证。

## 选择合同与保存结果

点击“选择合同”，在系统文件窗口选择合同。逐项复核后执行脱敏，会弹出“另存为”窗口，默认打开原合同所在文件夹。保存后同时得到两个文件：

- **脱敏文件**：文件内不保存原文映射，人工复核后可以外发或提供给 AI。
- **还原 JSON**：保存敏感原文，仅供自己还原，**不可外发或提供给 AI**。

不再区分两种 Word。不要把两个文件或整个文件夹一起发给 AI。JSON 请单独保管；Word 需要还原时，选择该脱敏 Word 和配套 JSON。PDF、TXT、Markdown 也有 JSON，但目前只有 Word 支持自动还原。

取消窗口不会保存到所选位置，可点“重新保存两个文件”。已有同名文件不会覆盖，请用新文件名。

## 安装后，从桌面图标打开

1. 双击下载的 `ContractRedactor-Setup-1.4.0.exe`，按向导点击“安装”。不需要解压 ZIP。
2. 安装完成后，双击桌面的“合同脱敏工具”图标。也可以在开始菜单中打开。
3. 浏览器打开本机页面后，点击“选择合同”，复核后按系统窗口保存。退出时点击网页右上角“退出”；只关闭标签页不会停止服务。

**不需要安装 Python，也不需要首次联网安装依赖。**运行环境已随安装程序提供。电脑已安装 Python 也照常使用，不重复安装或修改系统 Python、PATH、已有虚拟环境。合同处理无需 AI、模型账号或 API Key。

安装向导负责放置内部文件和创建快捷方式，日常只需使用桌面图标。安装程序用完后可以保留备份；以后不必再次安装才能启动。

## 安装位置与数据

默认仅为当前用户安装，位置为 `%LOCALAPPDATA%\Programs\ContractRedactor`，不修改系统 Python。

合同记录位于 `%LOCALAPPDATA%\ContractRedactor\Data\sessions`；错误日志为同目录下的 `startup.log`。退出工具不会删除合同记录。可以从 Windows“设置 → 应用 → 已安装的应用”卸载工具，卸载会移除程序和快捷方式，**保留合同记录和日志**，请按自己的保密与留存要求管理。

## 启动失败时

先访问 `http://127.0.0.1:18800/`。如果已有工具运行，可以直接使用；需要重启或更新时，请先从原工具网页退出。安装、卸载和启动器不会强制结束其他程序。

本安装包尚无代码签名。Windows 可能提示未知发布者；请核对来源与下载清单中的 SHA-256，再决定是否运行，不要关闭系统防护。如提示恶意软件，请停止并反馈。

## 发布前测试

必须在没有系统 Python 的 Windows 10/11 x64 测试环境完成：安装、桌面/开始菜单启动、首次断网启动、虚构 DOCX/PDF/TXT 的识别/对比/导出、重复启动、端口占用、退出、更新及卸载。确认卸载保留合同数据，并验证中文用户名路径。

## 修改脱敏规则

在软件内点击“打开规则文件”，用系统编辑器修改《脱敏规则清单.md》，保存后重新上传合同，按新规则识别。已经打开的识别结果不会自动刷新。Windows 用户规则独立存放在 `%LOCALAPPDATA%\ContractRedactor\Rules\脱敏规则清单.md`，首次启动创建默认副本，后续启动、升级或卸载不会覆盖或删除用户修改。无关联编辑器时，界面会显示文件位置，便于手动打开。Mac/源码版按钮打开当前生效的规则文件。
