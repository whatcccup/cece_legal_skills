# 合同脱敏工具｜开始使用

## 1.4.1：这次修复了什么

- 姓名不再只靠“原告、被告、联系人”等标签。新增正文语境识别，例如“赵星辰向朱宁支付款项”；识别确认的同名信息继续匹配全文其他位置。复姓也参与判断。
- 修复“6 000元”只替换“000元”、留下首位“6”的问题，完整识别带空格分组、千分位和多位小数的金额。
- 修复“6,000.00元”“600000元”等金额被误当作示例号码跳过的问题。
- 修复源码版 Windows BAT 启动文件行尾；普通用户继续使用 EXE 安装程序。

更新前从旧工具网页点击“退出”。Windows 运行新版安装程序；Mac 用对应芯片的新 App 替换旧 App。用户规则和合同记录会保留。更新后重新选择原文件识别，旧复核页面不会自动更新。若此前停用了姓名或金额类型，请先启用。

这次修复涉及程序内部判断，**只替换规则 MD 不能获得全部修复**。姓名仍是规则和语境识别，不保证覆盖所有罕见姓名、长姓名或外文姓名。发给他人或 AI 前，仍需人工检查姓名、金额及上下文。使用虚构样例测试，不要把真实合同交给 AI 排错。

## 不需要 AI Agent 安装提示词

Mac 与 Windows 新版已包含 Python 和依赖。没有 Python 可以直接使用，已有 Python 也不受影响；首次使用不需要联网安装依赖，不调用云端模型。

- Mac：在“关于本机”查看芯片，下载 Apple 或 Intel 版，完整解压，把“合同脱敏工具.app”拖到“应用程序”，双击打开。详情见 MAC-APP.md。
- Windows：双击安装程序，按向导安装，以后从桌面图标打开。详情见 WINDOWS-EXE.md。

点击“选择合同”，通过系统窗口选择原合同。逐项复核后执行脱敏，在“另存为”窗口保存，默认打开原合同所在文件夹。脱敏文件和 JSON 会一起保存。只有一种脱敏 Word，文档不内嵌原文映射；脱敏文件人工复核后可外发或发给 AI，JSON 含敏感原文，不可外发或发给 AI。

在工具内点击“打开规则文件”，将完整内容交给 AI Agent 修改，再把完整结果复制回原文件并保存，重新上传虚构样例验证。用户规则与合同记录独立保存，升级不覆盖规则，卸载不删除记录。原合同和还原 JSON 均需妥善保管。

退出时点击工具网页右上角“退出”，仅关闭标签页不会停止服务。端口占用时使用已打开的工具，或从原工具网页退出后重启，不结束其他程序。

Mac未获Developer ID签名/公证，Windows安装程序也尚未签名；按各系统说明核对来源和错误提示，不关闭系统防护。AI Agent只作为可选排错方式，不要向它提供真实合同或原文映射。
