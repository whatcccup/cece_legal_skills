# 法律业务辅助 Skill

1个主技能、24个子技能、六类工作流，覆盖材料整理、引用核验、证据分析、文稿完善及专业程序研究。按检察、律师或企业法务的身份与用途选择视角；专属程序不能直接照搬。

## 安装与使用

下载本目录内完整的 `legal-work-assistant/` 文件夹，放入宿主支持的技能目录。保留 `subskill/`、`workflows/` 和 `references/` 的相对位置；不要将子技能单独拆开安装。入口为 [SKILL.md](legal-work-assistant/SKILL.md)。

示例：“使用 legal-work-assistant，核对这份已脱敏文稿的引用，列出出处、差异和待核验项。”

AI宿主需支持读取本地Markdown；法律核验需要可用的权威来源检索，图像/音频转写需要对应工具。本包不自带数据库、OCR或语音模型；无法访问依据时须保留待核状态。

## 工作流与人工确认

范围与材料 → 事实/依据复核 → 业务分析 → 方向选择（需要时） → 指定版本审定。未收到确认不推进依赖步骤，材料改变后重新检查受影响分析。确认辅助成果不等于正式签发或对外发布。

## 版本与许可

公开版1.0.0，基于本地v04整理。MIT许可适用于本项目独立编写的技能与工作流；参考页面版权归原权利人，包内仅提供链接，不重新许可第三方原文。非官方发布或审定，未进行真实案件效果验证。
